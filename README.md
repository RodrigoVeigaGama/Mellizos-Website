# Mellizos Developer

Site institucional da Mellizos Developer, feito atualmente com JavaScript puro e componentes modulares.

Criação do site da Mellizos Developer.

## Desenvolvimento

```bash
npm install
npm run dev
```

O site abre em `http://localhost:3000`.

## Estrutura

- `index.html`: estrutura principal e conteúdo da página
- `style.css`: identidade visual e responsividade
- `script.js`: interações, tema, formulário, carrossel e animações
- `components/`: Navbar, Footer e modal de privacidade
- `public/images/`: imagens e assets públicos

O projeto permanece em JavaScript por enquanto. A migração para TypeScript pode ser feita depois, mantendo a mesma organização de componentes.
